# Hello World Webpage

This project is a simple HTML and CSS webpage that displays the message "Hello world" with rainbow-colored text. The text is centered on the page and has a responsive font size.

## Features

*   Displays "Hello world" message.
*   Rainbow-colored text using CSS linear gradient.
*   Text is centered on the page.
*   Responsive font size based on viewport width.
*   White background color.

## Getting Started

To view this webpage, simply open the `index.html` file in a web browser.

## Usage

This project can be used as a simple demonstration of HTML and CSS, or as a starting point for more complex web projects.
